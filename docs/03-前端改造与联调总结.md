### 2.2 `server/`（Express 4 + Mongoose 8 + MongoDB）

- **16 条路由**：health / meta / questions(2) / practice(2) / exams(5) / wrong-questions(4) / stats(1)。
- **5 个模型**：`Question`（`_id` 直接用 q001…）、`User`、`Exam`（试卷快照 + 逐题作答）、`AnswerRecord`、`WrongQuestion`（`clientId+questionId` 唯一）。
- **服务层**：`questionService`（题面 `toPublic` 不含答案、复盘 `toReview` 含答案、最大余额法按板块配额组卷）、`practiceService`（服务端判分 + 写流水/错题）、`examService`（幂等交卷、逐题报告）、`statsService`（聚合首页看板）、`seedService`（题库自举导入 + 建索引）。
- **中间件/基础设施**：`X-Client-Id` 匿名身份（含 5 分钟 lastSeen 节流）、统一 `{ error: { code, message } }` 错误处理、写接口限流、helmet/compression、优雅退出、dotenv 显式加载 `.env`。
- **数据与脚本**：`export-bank.js` 校验题库并按关键词规则打六大板块标签，产出 951 题的 `questions.array.json` / `questions.ndjson` / `topic-report.json`；`dev-memory.js`（内存 Mongo）、`smoke.js`、`prod-smoke.js`；`test/api.test.js` **13 个** `node:test` 用例。
- 本机无 `.env`（安全策略拦截），用开发默认值；生产由部署脚本从 `.env.example` 生成。

### 2.3 `deploy/`

`nginx.conf`（80、`/api/` 反代不带尾斜杠、`try_files` history 回退、gzip、`/assets` 长缓存、index 不缓存）、`ecosystem.config.js`（PM2 单实例 fork、300M 重启）、`deploy.sh`（本地打包上传 / 服务器部署双模式、`npm ci --omit=dev`、健康检查重试 15 次）、`push.ps1`（Windows 无 bash 时的等价封装）、`preflight.sh`（只读自检，OK/WARN/FAIL 三档）。

### 2.4 关键设计决策（对前端有直接影响）

1. **答案不下发、服务端判分**：`/api/questions`、`/practice/set`、`/exams/:id` 只给题面；`answer`/`explanation` 只在提交后返回 —— 这使"提交后右侧展开解析"成为真实交互而非前端假判分。
2. **匿名设备身份** `X-Client-Id`，免登录；前端 `request.ts` 生成并持久化到 localStorage。
3. **试卷快照落库**、**交卷幂等**、**未作答不计入错题**（`wrongCount` 只含"答了但错"）。
4. **接口分页 + gzip**：1 Mbps 带宽下首屏不加载 695 KB 题库。
5. 板块比例 17/15/20/16/16/16 是**考纲蓝图常量**，不是题库真实分布。
